# 🥗 Nutrify - Health & Nutrition Tracker

Nutrify is a full-stack MERN application designed to help users track their daily nutrition, manage meals, and stay healthy. This project allows users to register, log in, and monitor their food intake, calories, and other essential nutrition data.

---

## 🚀 Features

- ✅ User Authentication (Sign Up, Login)
- ✅ Dashboard to track daily food intake
- ✅ Calorie and macronutrient tracker
- ✅ Food database (add/view/edit meals)
- ✅ Responsive UI (Mobile + Desktop)

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- HTML/CSS
- Axios

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB (MongoDB Atlas)
